# Electronics Megastore SQL Project

## 📌 Project Overview

This project focuses on analyzing an electronics product inventory
and its manufacturers using SQL.

The project includes product pricing analysis, manufacturer analysis,
filtering, sorting, aggregation, and table joins.

## 🛠️ Tools & Technologies

- MySQL
- SQL
- dbeaver

## 🗄️ Database Structure

The project contains two main tables:

- Product_Inventory
- Manufacturers

The Product_Inventory table stores product information such as
product code, product name, price, and manufacturer code.

The Manufacturers table stores manufacturer codes and manufacturer names.

## 📊 Key Analysis Performed

- Product price analysis
- Manufacturer analysis
- Average and total price calculations
- Cheapest and expensive product analysis
- Product filtering
- Sorting products by price
- Product and manufacturer joins
- Aggregation using GROUP BY
- Filtering grouped data using HAVING
- Updating product prices
- Adding and updating products
